Key notes:

Python 3.12 is recommended (3.14+ has compatibility issues with porespy's dependencies)
If they use Python 3.13+, they should first create a Python 3.12 venv:

py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python Generators_3D.py

That's it — the requirements.txt file is now in the same folder as your script.
